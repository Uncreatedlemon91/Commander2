# Roadmap

| # | Milestone | Proof of done | Status |
|---|---|---|---|
| H0 | **Kit** | `kit/install.sh` installs a working `PROJECT/` + protocol into any repo | Done |
| H1 | **Read-only dashboard** | Deployed URL shows all registered projects, a "Needs you" list, task board, devlog, media and PR/CI status on phone and desktop | **Current** |
| H2 | **Capture & approve** | Add ideas to a project's inbox and answer decisions from the dashboard (commits via the GitHub API) | Planned |
| H3 | **Dispatch to Claude** | "Send to Claude" on a ready task starts a Claude run (GitHub issue + Claude GitHub app, or a Claude Code session) that ends in a PR + devlog entry | Planned |
| H4 | **Scheduled autonomy** | Opt-in scheduled runs with per-project limits, weekly status report, usage per task | Planned |
