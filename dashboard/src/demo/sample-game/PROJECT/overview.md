# Lantern Keeper — Overview

**Pitch:** A short-session roguelite where you keep a lighthouse lit through a
night-long storm. Climb, repair, ration oil, and guide ships past the rocks.

**Tech:** Godot 4.5, typed GDScript, web export for playtests.

**Phase:** Prototype. Current milestone: **M2: Storm night** (`roadmap.md`).
